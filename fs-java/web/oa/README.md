# oa(Office Automation，办公自动化)

自定义表单、自定义工作流。

## 功能模块

### 流程审批

- 新建单据：创建新的流程。
- 待签任务：从Candidate候选组中Claim签收任务。
- 待办任务：已签收但未处理的任务。
- 历史任务：由我发起或经我审批的全部任务。

### 工作流程

- 流程模型：设计工作流程，配置表单权限。
- 流程部署：已部署的工作流程，一个模型可多次部署。
- 流程管理：查看全部流程实例，可挂起、撤销、删除流程实例记录。

### 在线打印

- 上传 `.docx` 文件后，可在浏览器中分页编辑文字、表格、图片和常见段落格式，保存时会写回模板文件。
- 打印模板可关联一个 OA 表单，在预览页选择具体托管数据，或使用自动生成的示例数据验证版式。
- 单值占位符：`{{customerName}}`，也支持表单数据中的路径，例如 `{{customer.address}}`。
- 段落列表：使用 `{{?items}}` 与 `{{/items}}` 包裹循环内容，循环体内使用 `{{name}}`、`{{amount}}` 等字段。
- 表格行列表：在重复行上方的一行放置 `{{items}}`，重复行内使用 `[name]`、`[amount]`。该语法会保留每一行原有样式。
- 托管数据列表的“打印”操作可直接选择当前表单已启用的打印模板。

已有 OA 数据库升级时执行 `docs/fs-project-oa-print-upgrade.sql`。新环境可直接使用 `docs/fs-project-oa.sql`。

### 规划设计

- 候选分组：直属上级岗位、指定部门岗位、指定用户分组、指定用户。
- 分支判断：岗位职责。
- 多方会签：支持多用户任务和并行网关。
- 任务驳回：可驳回至上一节点，暂不打算支持任意节点跳转。
